# kripto-cuzdan

Bitcoin, Ethereum, Tron ve Monero hedefleyen, anahtarlari kullanicida kalan (non-custodial) Android cuzdan. Flutter ile yazildi.

## Durum (v0.1)
- PIN ile kilit (Android Keystore destekli sifreli depo)
- Cuzdan olusturma (12 kelime BIP39 seed), seed ile geri yukleme
- Cuzdan yeniden adlandirma, seed gosterme (PIN ister), silme (PIN ister)
- Coin adres/bakiye/gonderme: henuz yok (sonraki asamalar)

## APK nasil alinir
GitHub > Actions > "APK derle" > son calisma > Artifacts > `kripto-cuzdan-apk`.

> Gercek para koymadan once bagimsiz guvenlik denetimi yaptirin.
